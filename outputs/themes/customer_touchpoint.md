# 顧客接点を取られる｜テーマ別リサーチノート

## 1. テーマ概要

**論点:** 車内UI、スマホ連携、アプリ、購買接点、コンテンツ、広告、OTA接点を外部プレイヤーに握られるリスク。

**なぜ重要か:** OEMがブランドを持ちながらも、顧客との日常接点がサードパーティのOSやアプリに移行することで、サービス収益・顧客データ・ブランドロイヤルティが侵食される。

---

## 2. 関連企業マップ

| 企業 | 接点の種類 | 確度 |
|---|---|---|
| Huawei | コックピット（HarmonyOS）、AITO販売チャネル | 高 |
| Xiaomi | スマートフォンエコシステム統合（HyperOS Car） | 高 |
| Tencent | WeChat Car（メッセージ・決済・コンテンツ） | 高 |
| Alibaba | Alipay車内決済、Tmall Automotive（購買前） | 高 |
| ByteDance | 懂车帝（購買前情報）、Douyin（コンテンツ） | 高 |
| Baidu | Apollo Goによるラストマイル接点 | 中 |

## 4. トヨタ・OEMへの示唆

- 中国市場での顧客接点は既にByteDance・Tencent・Alibabaが掌握しつつある。
- MyToyotaアプリが購買前〜所有後の統合接点になれなければ、ブランドロイヤルティが希薄化するリスクがある。
