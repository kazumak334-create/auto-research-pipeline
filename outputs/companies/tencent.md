## 2. 自動車産業への関与領域

| 領域 | 内容 | 確度 | 根拠 |

| InCar | WeChat Car版、TAIコックピットソリューション | 高 | 公式発表 |

| Cloud / Data | Tencent Cloud for Automotive | 高 | 公式発表 |
| ADAS / 自動運転 | 自社ADASなし（クラウド・データ基盤のみ） | 高 | 公式発表 |
| Cockpit / Infotainment | TAI Cockpit（WeChat統合） | 高 | 公式発表 |
| Sales / CRM / 顧客接点 | WeChatを通じた購買・サービス接点 | 高 | 公式発表 |
| After-sales / OTA | クラウド経由OTAサポート（推定） | 中 | 推定 |

## 3. OEM侵食リスク評価

| 論点 | 評価 | 理由 | 根拠 | 確度 |
|---|---|---|---|---|
| 顧客接点を取るか | 高リスク | WeChatが中国市場の日常的コミュニケーション基盤であり、車内でも同様の地位を確立 | 公式発表 | 高 |
| 車両データを取るか | 高リスク | TAIを通じたコックピット利用データ・位置情報等をTencentが取得しうる | 推定 | 中 |
| 差別化領域を外部依存させるか | 高リスク | WeChatなしでは中国ユーザーにとってのUXが成立しない。OEM独自接点が失われるリスク | 公式発表 | 高 |
| OEM独自領域まで侵攻するか | 低リスク | Tencentは現時点でOEM車両製造に進出していない | — | 高 |

## 4. ASEAN・海外展開

| 地域 | 内容 | 根拠 | 確度 |
|---|---|---|---|
| Thailand | WeChatはタイ向けに対応（中国人観光客・移住者向け） | 推定 | 中 |
| Indonesia | WeChatはほぼ使われない（LINE/WhatsApp優位） | 一般知識 | 高 |
| Malaysia | WeChatは中国系移民層向け（限定的） | 推定 | 中 |
| Singapore | WeChat一定利用（中国系向け） | 推定 | 中 |
| Japan | WeChat Car版の日本展開は不明 | — | 不明 |
| Europe | GDPR制約によりTencent Cloud展開は限定的 | 推定 | 中 |
| United States | 安全保障上の規制リスク大 | 公式規制情報 | 高 |

## 5. トヨタ・既存OEMへの示唆

- 中国市場でWeChat Carが標準化されれば、OEMは顧客接点をTencentに依存する構造になる。
- ASEAN市場ではWeChat依存度は低いため、中国市場特有のリスクとして評価すべき。
